# LLM Inference Performance Lab

A hands-on project for understanding, benchmarking,
and optimizing LLM inference systems.

## Goals

- Implement a minimal autoregressive decoder
- Explore KV caching and memory management
- Implement request scheduling and batching experiments
- Benchmark vLLM serving performance
- Study MLC LLM inference runtimes
- Analyze latency, throughput, and GPU utilization

## Methodology

Build -> Measure -> Analyze -> Optimize -> Document
